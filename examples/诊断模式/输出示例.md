# 对标诊断报告：《理想与实干 / 自由与秩序》

## 1. 一句话判断

- **仿写是否合格：**勉强合格
- **整体相似度：**中
- **最大相似点：**都采用“两类人物 / 两种道路 / 最后二元收束”的结构。
- **最大偏差：**原文有更明显的文明史叙述感，仿写稿更像观点总结。
- **最该保留的仿写处理：**`一位害怕秩序吞没人，一位害怕没有秩序后人吞没人。`
- **最该重写的部分：**开头缺少“轴心时代 / 人类文明”这类时间高度。

## 3. 最像原文的 3 个地方

1. `一位害怕秩序吞没人，一位害怕没有秩序后人吞没人。`
   - 对应原文特征：双人物 / 双道路对照。
   - 为什么像：句式和功能都对应原文“一位以思想...一位以行动...”。

2. `没有自由，人会被规矩雕刻成工具。`
   - 对应原文特征：结尾二元判断。
   - 为什么像：延续“没有 X，文明便...”的收束方式。

3. `也有人站在宫阙之中`
   - 对应原文特征：通过人物位置制造历史画面。
   - 为什么像：不是直接说观点，而是先给空间位置。

## 4. 最不像原文的 3 个地方

1. `在漫长的历史深处`
   - 偏离维度：内容、语气。
   - 问题：比原文“轴心时代”更虚。
   - 怎么改：给出更明确的历史坐标。

2. `于是怀疑所有被称为治理的东西`
   - 偏离维度：作者立场。
   - 问题：判断太绝对，原文更克制。
   - 怎么改：改成“开始怀疑治理之名背后的权力”。

3. `工具`
   - 偏离维度：用词偏好。
   - 问题：现代抽象词重复太多。
   - 怎么改：替换为“笼中之物”“权力的形状”等更具画面感的词。

## 5. 修改优先级

### 必须先改

- 位置：开头。
- 原因：原文开头有文明史高度，仿写稿开头偏泛。
- 改法：加入明确时代或文明命题。

### 可以后改

- 位置：中段意象。
- 原因：仿写稿观点清楚，但画面少。
- 改法：增加城墙、竹简、宫阙等具体意象。

### 不需要改

- 位置：结尾二元收束。
- 原因：已经完成原文结尾功能。

## 6. 一句话

这篇仿写抓住了原文的“二元对照结构”，但还没抓住原文最值钱的“文明史画面感”。
