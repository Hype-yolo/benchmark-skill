# 产出模式说明

产出模式用于根据一篇原文生成新的仿写稿。

它的重点不是“马上写”，而是“先问清楚”。

## 输入格式

```text
/benchmark 产出模式

原文稿：
{原文}
```

## 工作流程

1. 分析原文的 16 项特征。
2. 按 16 项向用户提问。
3. 等用户回答。
4. 复述需求并让用户确认。
5. 用户确认后，再生成最终仿写稿。

## 为什么不能立即仿写

因为仿写不是复制原文。

用户可能想保留原文的结构，但改变主题；也可能想保留语气，但改变受众；还可能想把公众号长文改成短视频口播稿。

这些选择不问清楚，最终稿就会变成 AI 自己发挥。

## 用户需要回答什么

最关键的是这些：

- 新稿主题是什么
- 哪些原文特征要保留
- 哪些原文特征要改变
- 新增哪些内容
- 避免哪些内容
- 用在哪个平台或场景
- 目标篇幅或时长是多少
