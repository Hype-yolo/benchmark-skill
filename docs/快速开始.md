# 快速开始

`benchmark` 是一个文章对标改写 skill。它不负责凭感觉说“像不像”，而是把原文和仿写稿拆成 16 个维度检查。

## 安装

```bash
git clone https://github.com/Hype-yolo/benchmark-skill.git
mkdir -p ~/.agents/skills/benchmark
cp benchmark-skill/SKILL.md ~/.agents/skills/benchmark/SKILL.md
```

## 诊断模式

用于检查一篇仿写稿是否贴近原文。

```text
/benchmark 诊断模式

原文稿：
……

仿写稿：
……
```

输出结果会包含：

- 一句话判断
- 16 项对标诊断表
- 最像原文的 3 个地方
- 最不像原文的 3 个地方
- 修改优先级

## 产出模式

用于根据一篇原文生成新的仿写稿。

```text
/benchmark 产出模式

原文稿：
……
```

注意：产出模式不会立即仿写。它会先分析原文，再问你要保留什么、改变什么，确认后才生成最终稿。

## 最小使用建议

第一次使用时，建议先跑诊断模式。因为你会先看到原文到底由哪些维度组成，再决定下一篇要怎么仿。
