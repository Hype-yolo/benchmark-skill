# 16 项对标检查表

这 16 项是 `benchmark` 的核心判断框架。

| 编号 | 维度 | 要检查什么 |
|---|---|---|
| 1 | 内容 | 主题、题材范围、详略安排、事实与观点比例 |
| 2 | 结构 | 框架、段落功能、开头、过渡、结尾 |
| 3 | 语气 | 口吻、距离感、确定性、劝说意图、情绪温度 |
| 4 | 风格 | 整体气质、时代色彩、个性化笔法、视觉密度 |
| 5 | 目标受众 | 读者身份、知识背景、阅读目的、语言习惯 |
| 6 | 核心信息 | 中心观点、出现位置、强调方式、主次层级 |
| 7 | 关键数据 | 数字类型、精度、呈现方式、来源交代 |
| 8 | 用词偏好 | 高频词、术语、关联词、网络语、避讳词 |
| 9 | 情感 / 逻辑侧重 | 抒情还是说理、论证方式、感性与理性比例 |
| 10 | 人物与叙述视角 | 人称、视角、叙述者立场、时间线 |
| 11 | 修辞手法 | 比喻、排比、对偶、设问、用典、意象 |
| 12 | 词汇雅俗难易 | 书面或口语、难词比例、成语典故密度 |
| 13 | 句式长短与节奏 | 长短句、骈散比例、停顿、整齐度 |
| 14 | 作者立场 | 价值取向、立场鲜明程度、褒贬倾向 |
| 15 | 语体问题类别 | 文白程度、文体类别、正式度、标点体例 |
| 16 | 适用场景 | 发布环境、媒介、正式程度、篇幅与阅读方式 |

## 使用原则

不要把 16 项当成打分表。它们是用来定位偏差的。

一篇仿写稿可能内容贴合，但语体偏离；也可能风格贴合，但受众错位。真正的诊断要说清楚偏差发生在哪个维度。
