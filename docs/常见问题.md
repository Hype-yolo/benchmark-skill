# 常见问题

## 这个 skill 是写文案的吗？

不是普通写文案工具。它是对标改写工具。

诊断模式负责判断仿写稿像不像原文。产出模式负责先确认仿写要求，再生成最终稿。

## 为什么产出模式要先问问题？

因为用户通常不是想完全复制原文，而是想保留一部分、改变一部分。

如果不先问清楚，AI 会替用户擅自决定。

## 这个 skill 能不能用于短视频文稿？

可以。短视频文稿尤其适合检查：

- 开头方式
- 句式节奏
- 信息密度
- 语气强弱
- 适用场景

## 这个 skill 能不能用于古文、半文言、哲学辩论稿？

可以。它有专门的语体、词汇、修辞、句式和适用场景维度。

## 它和普通“模仿文风”有什么区别？

普通模仿文风通常只看词汇和句式。

`benchmark` 会同时看内容、结构、受众、核心信息、语体和场景。它更适合严肃对标。
