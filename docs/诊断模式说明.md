# 诊断模式说明

诊断模式用于比较两篇文章：

- 原文稿：你要模仿的标准
- 仿写稿：你已经写出来的版本

它的目标不是判断哪篇更好，而是判断仿写稿是否完成了对标。

## 输入格式

```text
/benchmark 诊断模式

原文稿：
{原文}

仿写稿：
{仿写稿}
```

如果没有清楚标注原文和仿写稿，skill 应该先要求用户标注，不应该自行猜测。

## 诊断顺序

1. 先拆原文 16 项特征。
2. 再检查仿写稿是否对应。
3. 最后给出修改优先级。

## 匹配度标准

- **高度贴合**：主要特征一致，只有细节差异。
- **基本贴合**：核心方向一致，但有明显颗粒度缺失。
- **部分贴合**：只模仿到表层。
- **偏离**：核心特征不一致。

## 诊断时最容易犯的错

- 只看主题相似，不看结构。
- 只看句式相似，不看受众。
- 只看文风相似，不看使用场景。
- 只说“相似度 70%”，不给具体修改方向。
